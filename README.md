# stella24

stella24 is a tool for **creating** and **editing** **ER models** for different database systems in a modern, welcoming and intuitive GUI.
Currently supported SQL dialects are:
- Oracle DB (PL/SQL)
- PostgreSQL
- SQLite

Main objectives of the application is **responsivity**, being user (especially **beginner**) **friendly**, with the option to
generate **DDL SQL queries** and export the **diagram** to a graphical format.

stella24 is written in **Rust** and uses the immediate GUI library **egui**.

## Supported OS:
- Windows (64bit)
- Linux (64bit)
- macOS (64bit)

There are plans to support WebAssembly.
